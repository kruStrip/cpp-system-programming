# Системное программирование на C++

Работа с системными вызовами, сборка через Make и CMake, небольшой учебный проект.

**Стек:** C++ · CMake · Make

## Что внутри

- `syscalls/` — примеры системных вызовов
- `sample-project/` — учебный проект со сборкой
- `bad-wordle/` — игра
- `CMakeLists.txt`, `Makefile` — сборка

## Запуск

```bash
cmake -B build && cmake --build build
```
