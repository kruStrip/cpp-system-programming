# Системное программирование на C++

Работа с системными вызовами, процессами и окружением, сборка через Make и CMake.

**Стек:** C++ · CMake · Make

## Что внутри

- `syscalls/` — примеры системных вызовов: копирование файла, память, echo, аргументы
- `environment/` — переменные окружения, процессы, pipe, запуск редактора
- `sample-project/` — учебный проект: процессы, загрузка библиотек, анализ
- `bad-wordle/` — игра в слова
- `CMakeLists.txt`, `Makefile` — сборка

## Запуск

```bash
cmake -B build && cmake --build build
```
